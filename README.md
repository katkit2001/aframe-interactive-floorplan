# Διαδραστική Κάτοψη Έξυπνου Σπιτιού (A-Frame)

Διαδραστική τρισδιάστατη κάτοψη σπιτιού, υλοποιημένη σε [A-Frame](https://aframe.io/), όπου ο χρήστης περιηγείται στον χώρο και αλληλεπιδρά με «έξυπνες» συσκευές (φώτα, τηλεόραση, ψυγείο, πόρτα, παράθυρο) για να δει και να αλλάξει την κατάστασή τους.

## Εκτέλεση τοπικά

Δεν απαιτείται build step — είναι απλό στατικό HTML/JS/CSS. Σέρβιρε τον φάκελο με έναν τοπικό web server, π.χ.:

```bash
python3 -m http.server 8123
```

και άνοιξε `http://localhost:8123`.

## Δομή

- `index.html` — η σκηνή A-Frame και το UI overlay
- `js/layout.js` — δηλωτική περιγραφή τοίχων/δωματίων
- `js/entities.js` — δηλωτική περιγραφή των διαδραστικών οντοτήτων
- `js/app.js` — custom component `interactive-entity` + δυναμική δόμηση σκηνής + UI λογική
- `css/style.css` — στυλ για τα HTML overlays (οδηγίες, info panel)

## Έλεγχοι

- **W A S D** — μετακίνηση
- **Σύρσιμο ποντικιού** — περιστροφή θέασης
- **Κλικ** σε αντικείμενο (φως, πόρτα, παράθυρο, συσκευή) — αλλαγή κατάστασης / εμφάνιση πληροφοριών
